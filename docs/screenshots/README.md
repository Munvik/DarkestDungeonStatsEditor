# Screenshots

This folder contains screenshots of the Darkest Dungeon Stats Editor application.

## How to Add Screenshots

To add screenshots to the main README:

1. Take screenshots of the application showing:
   - Main interface with hero list and weapons tab
   - Armor editing tab
   - Any other notable features

2. Save the images with descriptive names:
   - `main-interface.png` - Main window showing the complete interface
   - `armor-editing.png` - Armor tab view
   - Add more as needed

3. Place the images in this directory (`docs/screenshots/`)

4. The main README.md already references these images and will display them automatically once added

## Recommended Screenshot Content

### Main Interface Screenshot
- Left panel showing the hero list
- Weapons tab selected with sample data
- Global modification controls visible
- File load/save buttons

### Armor Editing Screenshot  
- Armor tab selected
- Data grid showing armor stats (Def, Prot, HP, Spd)
- Tab-specific percentage modifier controls

## Image Guidelines

- **Format:** PNG or JPG
- **Recommended Size:** 1200-1600px wide
- **Quality:** High quality, readable text
- **Content:** Show the dark theme and clean interface
- **Privacy:** Ensure no personal information is visible
